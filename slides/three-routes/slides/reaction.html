Kemp eliminase active site with the transition-state analogue 6NT bound. Reference geometry from the evolved Kemp eliminase HG3.17: Blomberg et al., Nature 503, 418–421 (2013).

The brief is a de novo Kemp eliminase for 5-nitrobenzisoxazole. We never see the substrate: every scored structure contains 6NT, a stable stand-in for the transition state, shown here bound in a real active site. Two residues do all the chemistry. A base takes the proton off the ring, the ring opens, and a donor catches the negative charge that appears.
