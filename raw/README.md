# raw/

The sources layer of this repository: third-party documents (a project brief, tooling guides) are saved here under
`YYYYMMDD_short-slug.ext` and never edited.

Nothing is published from this folder. The organizers' documents that were kept here during the project are third-party
material, so they were removed before publication, and `.gitignore` keeps new files here out of the repository.
Everything decision-relevant in them is distilled in `wiki/challenge.md`, `wiki/submission.md` and `wiki/cluster.md`.
