Server fingerprint, to check on first connection:
  SHA256:3HYAek1L/uZ+NT9YtwYhFBd9FUuz0vW06FWAurPTQWk

1. Put the key somewhere safe and lock its permissions.

     macOS / Linux:    chmod 600 pdh-team-01.pem
     Windows:          icacls pdh-team-01.pem /inheritance:r /grant:r "%USERNAME%:R"

2. Add this to your SSH config (~/.ssh/config, or
   C:\Users\YOUR_WINDOWS_USER\.ssh\config on Windows):

     Host pdh-team
         HostName <CLUSTER_IP>
         User ec2-user
         IdentityFile /full/path/to/pdh-team-01.pem
         IdentitiesOnly yes

3. Connect:

     ssh pdh-team

   On the first connection SSH shows the server fingerprint. It must match the
   value above. If it does not, stop and tell an organiser.
