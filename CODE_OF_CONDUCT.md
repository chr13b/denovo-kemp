# Code of conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(licensed CC BY 4.0), in short form.

**Our standard.** Be respectful and constructive. Criticise results, code and ideas, not people. Give credit where it is due.
Harassment, personal attacks, discrimination and publishing other people's private information are not acceptable.

**Scope.** This applies to every space of the project: issues, pull requests, discussions and review comments.

**Enforcement.** The maintainer may edit or remove comments, close threads and block accounts that break these rules.
To report a problem, use GitHub's own tools: the "Report content" option on the comment, or a private message to the
repository owner through their GitHub profile. Reports are handled in confidence.
